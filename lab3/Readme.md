## 🎮 Возможности

### Два режима игры
- **Игра с самим собой** — управление за оба цвета
- **Игра на двоих** — поочерёдный режим с автоматическим переворотом доски

### Полная шахматная механика
- Все стандартные фигуры с корректными правилами ходов
- **Рокировка** — специальный ход короля и ладьи
- **Взятие на проходе** (en passant) — особый ход пешки
- **Превращение пешки** — выбор любой фигуры при достижении последней горизонтали
- **Проверка шаха и мата** — автоматическое определение окончания игры

### Визуальные эффекты
- Плавная анимация перемещения фигур (15 кадров на ход)
- Индикация шаха (!)
- Автоматический переворот доски в режиме на двоих

### Звуковое сопровождение
- Фоновая музыка с регулировкой громкости
- Звуки ходов и взятий
- Звук мата и начала игры

### Система рекордов
- Сохранение имён победителей
- Статистика побед (всего, белыми, чёрными)
- Таблица лидеров с топ-15 игроков
- Медали 🥇🥈🥉 для первых трёх мест

## 🎮 Управление

| Действие | Клавиша |
|----------|---------|
| Выбор фигуры | ЛКМ (левая кнопка мыши) |
| Ход | ЛКМ на целевой клетке |
| Выход из игры / возврат в меню | `ESC` |
| Подтверждение имени | `Enter` |
| Возврат из справки/рекордов | `ESC` или клик мышью |

## Установка и запуск

### Требования
- Python 3.7 или выше
- Pygame 2.0+

### Структура проекта
chess-pygame/
│
├── chess.py                 # Основной файл игры
│
├── lib/                     # Ресурсы игры
│   ├── CASEFONT.TTF        # Шрифт для отображения фигур
│   ├── arial.ttf           # Основной шрифт для текста
│   ├── wood.jpg            # Текстура фона доски
│   ├── main.jpg            # Фоновое изображение
│   ├── highlight.png       # Подсветка выбранной фигуры
│   ├── blue.png            # Индикатор возможного хода
│   ├── red.png             # Индикатор взятия
│   ├── castling.png        # Индикатор рокировки
│   ├── in_passing.png      # Индикатор взятия на проходе
│   ├── check_filled.png    # Индикатор шаха
│   ├── danger_filled.png   # Индикатор опасности
│   ├── instruction.PNG     # Экран инструкции
│   └── butt.jfif           # Кнопка перехода
│
├── sounds/                  # Звуковые файлы (опционально)
│   ├── move.mp3            # Звук хода
│   ├── checkmate.mp3       # Звук мата
│   ├── game_start.mp3      # Звук начала игры
│   └── background_music.mp3 # Фоновая музыка
│
├── records.json             # Файл с рекордами (создаётся автоматически)
└── notation.txt            # Запись последней партии (создаётся автоматически)
